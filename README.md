# Vite SPA Boilerplate

A modern boilerplate for building single-page applications with Vite.

## Features

- ⚡️ **Vite** - Fast build tool and development server
- 🔥 **Hot Module Replacement** - Instant updates during development
- 📦 **Modern JavaScript** - ES modules support
- 🎯 **TypeScript Ready** - Optional TypeScript support
- 🛠️ **Developer Experience** - Optimized for modern web development

## Quick Start

```bash
# Clone the repository
git clone https://github.com/Dekel42/vite-spa-boilerplate.git
cd vite-spa-boilerplate

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
vite-spa-boilerplate/
├── public/          # Static assets
├── src/             # Source code
│   ├── main.js      # Application entry point
│   └── style.css    # Global styles
├── index.html       # HTML template
├── package.json     # Dependencies and scripts
└── vite.config.js   # Vite configuration
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Customization

This boilerplate provides a minimal setup. You can extend it by:

- Adding your preferred framework (React, Vue, Svelte, etc.)
- Configuring additional build tools
- Setting up testing frameworks
- Adding CSS preprocessors
- Integrating state management solutions
